# Building GlyphShift binaries

PyInstaller **cannot cross-compile**. You must build on the same OS as the target:

| Target | Build machine |
|--------|----------------|
| Windows `.exe` | Windows |
| macOS (no extension) | macOS |
| Linux (no extension) | Linux |

CI does this automatically on every tag `v*` via [`.github/workflows/release.yml`](../.github/workflows/release.yml).

---

## Prerequisites (all platforms)

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate

python -m pip install --upgrade pip
pip install -e ".[dev,gui]"
```

Python **3.9+** (CI uses 3.12). GUI builds need PySide6 (included in `[dev,gui]`).

---

## Windows

### One-shot script

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```

Outputs (under `release-bin/`):

- `glyphshift-windows.exe` — CLI
- `glyphshift-gui-windows.exe` — GUI (windowed, no console)

### Manual commands

```powershell
pyinstaller --noconfirm --clean --onefile --name glyphshift --paths src src\glyphshift\cli.py

pyinstaller --noconfirm --clean --onefile --windowed --name glyphshift-gui `
  --paths src --hidden-import PySide6 --collect-all PySide6 `
  src\glyphshift\gui\__main__.py

New-Item -ItemType Directory -Force -Path release-bin | Out-Null
Copy-Item dist\glyphshift.exe release-bin\glyphshift-windows.exe -Force
Copy-Item dist\glyphshift-gui.exe release-bin\glyphshift-gui-windows.exe -Force
```

### Run

```powershell
.\release-bin\glyphshift-windows.exe --version
.\release-bin\glyphshift-gui-windows.exe
```

SmartScreen may warn on unsigned builds — that is expected until you code-sign.

## macOS

### One-shot script

```bash
chmod +x scripts/build_unix.sh
./scripts/build_unix.sh macos
```

Outputs:

- `release-bin/glyphshift-macos`
- `release-bin/glyphshift-gui-macos`

### Manual commands

```bash
pyinstaller --noconfirm --clean --onefile --name glyphshift --paths src src/glyphshift/cli.py

pyinstaller --noconfirm --clean --onefile --windowed --name glyphshift-gui \
  --paths src --hidden-import PySide6 --collect-all PySide6 \
  src/glyphshift/gui/__main__.py

mkdir -p release-bin
cp dist/glyphshift release-bin/glyphshift-macos
cp dist/glyphshift-gui release-bin/glyphshift-gui-macos
chmod +x release-bin/glyphshift-macos release-bin/glyphshift-gui-macos
```

### Notes

- On Apple Silicon, builds are arm64; on Intel Macs, x86_64. Build on the architecture you ship for.
- First launch may require **System Settings → Privacy & Security** if Gatekeeper blocks an unsigned binary.
- Optional: wrap in a `.app` / `.dmg` later; the one-file binary already runs from Terminal or Finder.

### GUI dependencies

For the GUI binary on a minimal desktop, install usual Qt/X11 libs (distro-specific), e.g. on Debian/Ubuntu:

```bash
sudo apt-get install -y libxcb-cursor0 libxkbcommon-x11-0 libegl1
```

Headless CLI-only use does not need these.

## Python packages (sdist / wheel) — any OS

These are OS-independent and **can** be built on any machine:

```bash
pip install build
python -m build
# → dist/glyphshift-*.whl and dist/glyphshift-*.tar.gz
```

Publish:

```bash
pip install twine
twine upload dist/*
```

## GitHub Release (recommended for shipping)

1. Commit and push `main`
2. Create and push a version tag:

```bash
git tag v0.1.0
git push origin v0.1.0
```

3. The **Release** workflow builds:
   - sdist + wheel
   - Windows / macOS / Linux PyInstaller binaries  
   and attaches them to the GitHub Release.

---

## What not to commit

Do **not** commit these folders (already in `.gitignore`):

- `build/`, `dist/`, `release-bin/`
- `*.spec` generated by PyInstaller (optional; we ignore them)

Ship binaries via GitHub Releases or a local `release-bin/` folder only.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `ModuleNotFoundError: PySide6` in GUI exe | Rebuild with `--collect-all PySide6` / `--hidden-import PySide6` |
| Huge GUI exe size | Normal for Qt one-file; use onedir if you need smaller downloads |
| WOFF2 fails at runtime | Ensure `brotli` is installed before build (`pip install -e ".[dev,gui]"`) |
| Cross-OS binary won't run | Rebuild on that OS — PyInstaller is not portable across OS families |
